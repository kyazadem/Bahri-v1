# 🦐 Bahri — QR Restaurant Ordering

Multi-tenant QR-code restaurant ordering app. Diners scan a QR code at their table, browse the menu, order from their phones, and call waiters with one tap. Kitchen staff see live orders in real time.

## Tech Stack

| Layer | Tech |
|-------|------|
| Frontend | React 18 + TypeScript + Tailwind CSS + Vite |
| Backend / DB / Auth | Supabase (Postgres + Auth + Realtime + RLS) |
| Icons | Lucide React |

## Quick Start

npm install
npm run dev
